# Kzera Perfil 1.0.6 - Detecção de Duplicidade

## Regras

- Duplicidade nunca bloqueia automaticamente.
- O sistema sinaliza possíveis duplicados.
- Critérios:
  - telefone igual;
  - e-mail igual;
  - nome muito parecido.
- Perfis arquivados não entram na análise padrão.
- A decisão final é do usuário.

## Uso

- Antes de criar perfil.
- Após importação.
- Na central de pendências.
