# Kzera Perfil 1.0.1 - Importação com Ajustes por Registro

## Regras

- O arquivo importado não precisa conter `Conhece Pessoalmente`.
- A prévia de importação deve exibir um checkbox `Conhece Pessoalmente` para cada registro.
- O usuário pode marcar/desmarcar esse campo antes de confirmar a importação.
- O arquivo pode vir sem bairro.
- A prévia deve permitir preencher/ajustar `Bairro` por registro.
- A cidade/município padrão da importação é `Brasília`.
- A prévia deve permitir alterar a cidade por registro, se necessário.
- Nome continua obrigatório.
- Codigo não é importado.
- Codigo só será definido depois, quando houver bairro e o usuário clicar em `Definir`.

## Campos da prévia

- Nome
- Telefone
- E-mail
- Bairro
- Cidade
- Conhece Pessoalmente
- Status de validação
- Erros do registro
