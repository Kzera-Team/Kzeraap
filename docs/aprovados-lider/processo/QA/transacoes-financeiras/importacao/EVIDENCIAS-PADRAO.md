# Evidencias padrao QA

Modulo: Importacao de Transacoes
Status inicial: Aguardando evidencia

## Regra Rose

Sem evidencia suficiente, nao aprova.

## Evidencia minima por caso

- ID do caso
- data da execucao
- branch testada
- ambiente usado
- responsavel pela execucao
- massa de teste usada
- passos executados
- resultado esperado
- resultado obtido
- prints ou video quando visual
- arquivo usado quando houver importacao
- comparacao antes e depois quando houver risco
- erro encontrado se houver
- status final

## Evidencia tecnica da rodada

- TypeScript sem erro
- build sem erro
- testes automatizados existentes, se houver

## Evidencia de estoque

Quando houver risco de impacto em estoque:

- estoque antes
- estoque depois
- lote antes
- lote depois
- quantidade disponivel antes
- quantidade disponivel depois

## Status permitidos

- Aprovado
- Reprovado
- Bloqueado
- Aguardando evidencia
- Aprovado com ressalva
