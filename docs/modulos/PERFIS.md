# MÓDULO — PERFIS

## Regras

- Cliente é chamado de Perfil na UI.
- Perfil possui cadastro, busca, histórico, pendências, duplicidades, importação e exportação.
- Clique simples abre Dashboard do Perfil.
- Dados pessoais definidos como sensíveis devem seguir regra de segurança.
- Campo “Conhece pessoalmente” deve existir quando aplicável.
- Status conhecidos: Ativo e Arquivado.

## Proibido

- Voltar a usar “Cliente” na UI.
- Misturar cadastro com listagem quando a decisão for tela separada.
- Remover dado histórico sem regra explícita.
