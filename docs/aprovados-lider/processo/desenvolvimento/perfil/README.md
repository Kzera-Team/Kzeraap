# Perfil — desenvolvimento

Módulo responsável por cadastro, edição, identificação, classificação, histórico e importação de Perfis.

No KZERA, Perfil é o termo preferencial para o antigo conceito de cliente, salvo contexto legado documentado.

## Fluxos previstos

```text
cadastro/
importacao/
classificacao/
historico/
identificacao/
```

## Estrutura por fluxo

```text
<fluxo>/
  README.md
  regras/
  mockups/
  fluxos/
  decisoes/
  pendencias/
```

## Diretrizes já conhecidas

- Listagem serve para encontrar.
- Cadastro e edição devem ficar em tela própria.
- Não misturar listagem com formulário grande para economizar clique.
- Identidade real pode exigir proteção conforme regras de segurança.
- Código do Perfil deve ser configurável por blocos quando aplicável.
