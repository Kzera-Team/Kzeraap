# Kzera Foundation 1.1.0

Objetivo: encerrar a fase Foundation e definir o contrato para os módulos futuros.

## Entregue na Foundation

- Arquitetura modular TypeScript
- Core / Domain / Application / Infrastructure / Presentation
- AccessCoordinator
- SessionContext
- ResourceScope
- PerfilRepository
- TableObfuscator
- Fluxos de autenticação
- Persistência base
- Contratos de backup
- Contratos de identidade operacional

## Pendências que ficam para os módulos funcionais

- Implementação visual da regra de codigo
- Backup criptografado real
- Importação real de backup
- Perfil funcional completo
- Item
- Transacao
- Lote
- Campanhas
- Backend

## Critério de encerramento da Foundation

A partir desta versão, novas entregas devem ocorrer em módulos funcionais
e não mais em versões incrementais da fundação.
