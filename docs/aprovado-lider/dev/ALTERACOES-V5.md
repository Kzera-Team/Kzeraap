# Alterações V5 — Regra Suprema primeiro e prompt principal enxuto

## Correção principal

A Regra Suprema agora é literalmente a primeira coisa útil do prompt principal.

Antes, ela ficava perto do topo, mas depois da identidade e do cabeçalho.  
Agora vem antes de identidade, papel, tom, escopo, autorização, checklist, status e qualquer outro documento.

## Enxugamento

O prompt principal foi reduzido para manter apenas:

- Regra Suprema;
- identidade;
- ordem direta/autorização;
- trava documental;
- limite de papel;
- arquitetura obrigatória resumida;
- status FINAL/PARCIAL/BLOQUEADA;
- verificação antes da entrega;
- lista de auxiliares;
- formato mínimo de entrega.

Detalhes longos permanecem nos auxiliares.
