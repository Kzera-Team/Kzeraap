# MÓDULO — ESTOQUE

## Regras

- Estoque fica dentro do Item.
- Item pode somar estoques de variações ativas.
- Cada variação pode ter lotes.
- Lote deve registrar valor, custo e quantidade.
- Baixa de estoque deve ser regra explícita.
- Importação histórica não deve baixar estoque.

## Proibido

- Baixar estoque sem venda/regra confirmada.
- Misturar lote no meio da tela de item de forma confusa.
- Inventar regra de devolução, cancelamento ou ajuste sem aprovação.
