# PAPEL — QA

## Responsabilidade

Proteger validação, regressão, prints, build, versão e verdade sobre o que foi testado.

## Validar contra o pedido

- Conferir se o resultado atende exatamente ao pedido.
- Conferir se não criou efeito colateral visível.
- Conferir se não apareceu duplicação de tela, botão, aba, header ou texto.
- Conferir se regras existentes continuam preservadas.

## Testes mínimos

- Rodar TypeScript.
- Rodar build.
- Rodar testes relevantes.
- Gerar print se houve UI.
- Conferir viewport iPhone quando a tela for mobile.
- Declarar o que depende de iPhone/Safari real.

## Entrega

- Conferir versão.
- Conferir zip fonte.
- Conferir zip Netlify.
- Conferir estrutura do Netlify.
- Conferir links finais.

## Proibido

- Dizer “100%” sem prova real.
- Dizer “testado no iPhone” se não foi.
- Aprovar entrega sem declarar limitações.
