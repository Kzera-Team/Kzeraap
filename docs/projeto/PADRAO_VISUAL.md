# PADRÃO VISUAL

Documento obrigatório para alterações de UI.

## Regras

- Mobile-first para iPhone.
- Preservar padrão visual aprovado.
- Não criar header, aba, botão ou texto duplicado.
- Não redesenhar sem pedido.
- Não criar bloco vazio grande.
- Ação principal deve ser visível.
- Estado vazio deve orientar a usuária.
- Erro deve ser claro e corrigível.
- Texto deve ser curto e direto.
- Safe area, teclado e leitura no iPhone devem ser considerados.

## Antes de aprovar UI

- Gerar print.
- Simular uso real.
- Conferir se a tela ficou menos confusa.
- Conferir se a Senhora Cansada conseguiria usar sem adivinhar.

## Proibido

- UI bonita que aumenta esforço.
- Mudança visual sem motivo.
- Resolver integração visual escondendo elementos com CSS quando deveriam sair da renderização.
