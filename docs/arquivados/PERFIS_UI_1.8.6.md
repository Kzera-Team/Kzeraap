# Kzera 1.8.6 - UI Funcional de Cadastro de Perfis

## Entregue

- Tela navegável em `public/index.html`.
- Formulário de criação de perfil.
- Busca operacional.
- Dashboard de pendências.
- Lista de perfis.
- Arquivar e reativar.
- Definir código quando houver bairro.
- Importação por arquivo com prévia editável.
- Edição de bairro, cidade e conhece pessoalmente na prévia.
- Confirmação de importação.
- Lista de possíveis duplicidades.
- Exportação CSV sem nome real por padrão.
- CSS responsivo mínimo para iPhone.

## Limites

Esta é uma UI funcional mínima, não o design final visual do produto.
Ela fecha o fluxo operacional do cadastro para validação e evolução.
