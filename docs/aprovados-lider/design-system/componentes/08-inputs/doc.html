08 — Inputs

Input Field

Proposto

Campo de entrada de texto para formulários. Cobre texto livre, senha com toggle, campos com máscara e todos os estados de validação. Componente único — nenhuma tela inventa seu próprio input.

Causa sistêmica — por que este componente foi criado agora
Causa do sistema (Lia): O design system documentava o container de formulário (form.css) mas não o campo em si. Cada dev criava inputs com heights, radius e estados inconsistentes entre telas.

Causa do processo (Helena): Sem componente de referência, o processo aceitava criação de input ad-hoc sem consulta ao design system. Inputs com font-size abaixo de 16px causavam zoom involuntário no iOS da senhora cansada.

Regras UX — Helena
✗
Nunca usar placeholder como substituto de label
Quando a senhora cansada começa a digitar, o placeholder some. Se não houver label visível, ela perde o contexto do campo. Label sempre presente, sempre acima do campo.
✗
Nunca mostrar erro apenas pela cor da borda
A senhora cansada pode não distinguir cores. O erro precisa de texto explicativo no helper: o que errou e como corrigir. Cor reforça — não substitui o texto.
✗
Nunca usar font-size abaixo de 16px dentro do input
iOS faz zoom automático em inputs com font-size < 16px. O zoom quebra o layout e desorienta. Usar sempre --t-md (1rem = 16px) no campo. Label e helper podem ser 14px.
✓
Erro antes do submit — não só depois
Se possível, mostrar validação em tempo real (ao sair do campo). Não forçar a senhora cansada a preencher tudo e descobrir erros apenas ao tentar avançar.
✓
Toggle de senha com área de toque 48×48px
O ícone de olho tem ~20px, mas a área clicável deve ser 48×48px. Dedo dolorido de reumatismo não acerta ícone pequeno. O .kz-field-toggle já garante isso.
✓
inputmode correto para cada tipo de dado
inputmode="numeric" para CPF/CNPJ/CEP — teclado numérico no celular. inputmode="tel" para telefone. inputmode="email" para e-mail. Reduz erro de digitação.
Checklist — senhora cansada
1
Ela consegue ler o que está digitando?
Texto do campo: --kz-light-text sobre --kz-light-surface. Contraste muito acima de AA. ✓
2
Ela sabe o que colocar no campo?
Label visível acima + placeholder com exemplo concreto. Não genérico: "Ex.: Maria da Silva", não "Digite aqui".
3
Ela entende o erro imediatamente?
Texto de erro direto e específico: "CPF inválido. Verifique e tente novamente." — não "Erro no campo".
4
O campo é grande o suficiente para clicar com dedo dolorido?
48px de altura garantido por --space-12. Não reduzir por nenhum motivo estético.
5
A tela não dá zoom ao tocar no campo?
Font-size do input = 1rem (16px). Se zoom acontecer, verificar se o valor de font-size foi sobrescrito.
