# MÓDULO — ITENS

## Regras

- Produto é chamado de Item na UI.
- Itens possuem catálogo, busca, importação e listagem.
- Cadastro de novo item deve ser tela própria quando aplicável.
- Estoque pertence ao Item como aba interna.
- Item pode ter variações.
- Variação pode ter estoque próprio.
- Lote pertence à variação.

## Proibido

- Voltar a usar “Produto” na UI.
- Tratar estoque como módulo solto quando a regra for aba do Item.
- Misturar cadastro e listagem sem aprovação.
