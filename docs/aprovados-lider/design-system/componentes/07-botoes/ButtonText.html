SVG sempre com aria-hidden="true" — o texto do botão já descreve a ação para leitores de tela.
Loading
primary
secondary
/* Adicione kzera-btn--loading e aria-busy via JS (ver seção abaixo) */
<button class="kzera-btn kzera-btn--primary kzera-btn--loading"
        type="button"
        aria-busy="true">
  <span class="kzera-btn__text">Salvando...</span>
</button>
O texto fica transparente mas permanece no DOM — mantém a largura do botão estável. O spinner aparece no centro. aria-busy="true" avisa leitores de tela que a operação está em andamento.

Como ligar o clique
Use event delegation — um único listener ouve todos os cliques e despacha pelo data-action. Não adicione um listener separado por botão.
// No arquivo da tela — ex: PedidosScreen.ts

document.addEventListener('click', (e) => {
  const btn = (e.target as Element)
    .closest<HTMLButtonElement>('[data-action]')
  if (!btn || btn.disabled) return

  switch (btn.dataset.action) {
    case 'confirmar-pedido': confirmarPedido(); break
    case 'cancelar':         fecharModal();     break
    case 'excluir-pedido':   excluirPedido();   break
  }
})
Como ativar e desativar loading
async function confirmarPedido() {
  const btn = document.querySelector<HTMLButtonElement>(
    '[data-action="confirmar-pedido"]'
  )
  if (!btn) return

  // ativa loading
  btn.classList.add('kzera-btn--loading')
  btn.setAttribute('aria-busy', 'true')
  btn.disabled = true

  try {
    await api.confirmar()
  } finally {
    // desativa loading
    btn.classList.remove('kzera-btn--loading')
    btn.removeAttribute('aria-busy')
    btn.disabled = false
  }
}
