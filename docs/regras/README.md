# Kzera — Regras do Sistema

- **`CLAUDE.md`** (raiz do repositório) → versão enxuta oficial das regras, em uso.
- **`R1_DeclaracaoModo.md`** até **`R11_Divergencia.md`** → textos completos de cada seção (referência e preservação total do contexto).

1. O `CLAUDE.md` da raiz é a regra oficial do orquestrador.

3. Qualquer mudança só é feita após autorização explícita do líder, trecho a trecho.
