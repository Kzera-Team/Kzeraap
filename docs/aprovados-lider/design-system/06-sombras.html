06 — Sombras

4 níveis de elevação + 1 sombra de destaque. A cor base das sombras usa #120B35 — o roxo-escuro do sistema — em vez de preto puro, mantendo coerência com a paleta.

Escala de elevação
TokenValorDemo
--shadow-0 none
--shadow-1 0 1px 4px rgba(18,11,53,.07)
--shadow-2 0 4px 12px rgba(18,11,53,.10)
--shadow-3 0 8px 32px rgba(18,11,53,.16)
--shadow-accent 0 4px 16px rgba(123,77,255,.30)

--shadow-accent é exclusivo para botão primário e FAB — glow roxo que reforça a identidade do acento.

Mapeamento semântico — o que usar onde
TokenComponentes
--shadow-0
Item de lista Row de tabela Fundo de tela
--shadow-1
Card de pedido Card de cliente Card de transação Input focado
--shadow-2
Card de métrica Card de seção destacado Dropdown / overflow menu
--shadow-3
Bottom sheet Modal de confirmação Drawer lateral
--shadow-accent
Botão primário FAB (+)
Regras de uso
1
Nenhum componente usa box-shadow com cor fixa. Sempre via token.
2
--shadow-accent apenas em botão primário e FAB. Nunca em cards ou elementos passivos.
3
No tema Dark (--vv-*): reduzir opacidade de todas as sombras em 50% — fundo escuro absorve mais a sombra.
4
Cards dentro de bottom sheet usam --shadow-0 — a sombra já está no sheet, não nos itens internos.
Por que #120B35 e não preto? Sombras com a cor base do sistema (#120B35) têm um tom levemente roxo que integra com a paleta. Sombra preta pura em fundo purple-tinted cria um contraste artificial.
