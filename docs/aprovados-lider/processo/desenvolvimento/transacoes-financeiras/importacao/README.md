# Importação de Transações Financeiras — Desenvolvimento

Estrutura oficial do conteúdo documental seguindo a regra:

Produto -> módulo -> fluxo -> tipo de documento

## Estrutura

- mockups/: protótipos e telas estáticas do fluxo de importação
- regras/: regras, critérios de negócio e históricos de decisão

## Objetivo

Centralizar a documentação de desenvolvimento do módulo de importação de transações financeiras sem alterar o código-fonte nem a experiência do usuário.
