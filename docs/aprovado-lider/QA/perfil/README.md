## Critérios gerais

- Perfil não deve ser criado automaticamente por importação financeira sem regra explícita.
- Fluxos de cadastro e edição precisam ter evidência visual e funcional.
- Campos protegidos devem respeitar as regras já definidas para o projeto.
- Terminologia deve usar Perfil no lugar de cliente, salvo contexto legado autorizado.
