# Kzera Perfil 1.1.0 - Módulo Consolidado

## Incluído

- Criar perfil.
- Listar perfis.
- Buscar/selecionar perfis.
- Arquivar e reativar.
- Importação CSV/TSV/TXT/XLS/XLSX.
- Prévia editável de importação.
- Cidade padrão Brasília.
- Conhece pessoalmente por registro na prévia.
- Bairro opcional.
- Codigo imutável.
- Definir codigo apenas quando houver bairro.
- Codigo único.
- Detecção de duplicidades.
- Mesclagem com arquivamento do secundário.
- Dashboard de pendências.
- Exportação CSV.
- Configuração/preview da regra de identidade operacional.

## Regras preservadas

- Perfil nunca é excluído.
- Arquivado não aparece em busca padrão.
- Nome é obrigatório.
- Codigo não é importado.
- Codigo, depois de definido, congela.
- Nova regra de codigo só vale para novas definições.
- Exportação por padrão usa codigo/sem codigo, não nome real.
