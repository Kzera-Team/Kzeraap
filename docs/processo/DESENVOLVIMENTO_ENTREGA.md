

## Perguntas obrigatórias no final da entrega

Toda entrega deve responder objetivamente:

1. Todos os documentos obrigatórios foram lidos item a item?
2. Algum código ruim foi encontrado e registrado como dívida técnica?
3. O checklist de entrega foi preenchido item a item?
4. O código entregue é o mais limpo e legível possível dentro do escopo aprovado?

Se qualquer resposta for parcial, a entrega não deve ser apresentada como final.
