# Kzera Perfil 1.0.0

Primeiro módulo funcional construído sobre a Foundation.

## Regras implementadas

- Perfil exige nome.
- Perfil nunca é excluído.
- Perfil pode ser arquivado e reativado.
- Perfil importado pode vir sem bairro.
- Perfil sem bairro pode existir.
- Perfil sem codigo pode existir.
- Botão/ação de definir codigo só deve aparecer quando houver bairro e o codigo estiver vazio.
- Codigo é imutável.
- Regra nova de codigo só vale para novos perfis/novas definições.
- Codigo deve ser único.
- Busca/listagem padrão não mostra arquivados.
- Pendências incluem:
  - sem bairro;
  - sem codigo;
  - apto para definir codigo.

## Fora do escopo desta versão

- UI visual final.
- Importação de planilha real.
- Item.
- Transacao.
- Relatórios.
