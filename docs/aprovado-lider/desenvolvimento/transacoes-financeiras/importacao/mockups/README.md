# Mockups — Transações financeiras / Importação

Fluxo de UX para importação e confirmação histórica de transações financeiras.

Estes arquivos são referências visuais aprovadas para desenvolvimento e validação de fluxo.

## Arquivos

1. `00-importar-historico-financeiro.html` — tela vazia, antes de carregar arquivos.
2. `00-importar-historico-financeiro-carregado.html` — tela com transações e financeiro carregados.
3. `01-importacao-em-andamento.html` — importação em andamento e resumo inicial.
4. `02-resolver-pendencias.html` — bloqueios agrupados e resolução de pendências.
5. `03-previa-segura.html` — prévia segura antes da confirmação.
6. `04-confirmacao-bottom-sheet.html` — confirmação final por bottom sheet.
7. `05-recuperacao.html` — recuperação de confirmação interrompida.
8. `06-detalhes-avancados.html` — detalhes avançados do pacote congelado.

## Regra

Mockup não é teste executado.

QA deve comparar estes mockups com:

- documentação de regras;
- casos de teste;
- evidência real do app rodando;
- contadores exibidos na interface;
- comportamento real de confirmação, recuperação e estoque.
